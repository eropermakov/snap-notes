# Snap Notes

Заметки для Windows в духе Google Docs: сетка карточек, глобальный хоткей для скриншота области экрана, умное распознавание текста (включая таблицы/кнопки/списки) через Gemini, Groq или локальный офлайн-OCR прямо в открытой заметке.

## Стек

Electron + React + TypeScript (electron-vite), Tailwind CSS, Framer Motion, Zustand, electron-store, electron-updater, `@google/genai`, Groq (REST), `tesseract.js`, `auto-launch`, `adm-zip`, `sanitize-html`, `string-similarity`, `react-masonry-css`.

## Запуск в режиме разработки

```bash
npm install
npm run dev
```

Откроется окно приложения с горячей перезагрузкой renderer-а. При первом запуске появится визард настройки (API-ключи, тема, хоткеи, автозапуск).

Полезные команды:

```bash
npm run typecheck   # проверка типов (main + renderer)
npm run build        # сборка main/preload/renderer в out/
```

## Сборка установщика (локально, без публикации)

```bash
npm run dist
```

Соберёт production-бандл и запустит `electron-builder --win` (NSIS). Готовый `Snap Notes Setup <версия>.exe` появится в `release/`. Распакованная версия — в `release/win-unpacked/`.

## Публикация релиза (для автообновлений)

Автообновление работает через GitHub Releases (репозиторий `eropermakov/snap-notes`, настроено в `package.json` → `build.publish`). Чтобы выпустить версию, которую подхватят уже установленные копии приложения:

1. Поднимите `version` в `package.json`.
2. Добавьте запись в `CHANGELOG.md` и в `src/shared/changelog.ts` (это то, что увидит пользователь в диалоге «Что нового»).
3. Получите GitHub Personal Access Token с правом `repo` и экспортируйте его:
   ```bash
   export GH_TOKEN=ghp_xxxxxxxx
   ```
4. Соберите и опубликуйте:
   ```bash
   npm run release
   ```
   Это соберёт установщик и сразу загрузит его в GitHub Releases репозитория как черновик/релиз с файлами обновления (`latest.yml` и т. д.), которые `electron-updater` использует для проверки версий.

Уже установленные копии Snap Notes проверяют обновления при старте и затем каждые 4 часа, скачивают их в фоне и показывают баннер «Перезапустить». Проверить вручную можно кнопкой «Проверить обновления» в Настройках.

Инсталлятор не подписан сертификатом — Windows SmartScreen может предупредить при первой установке, это ожидаемо для проектов без code-signing сертификата.

```bash

```

Результат: `build/icon.ico` (для .exe) и `resources/icon.png` (иконка окна/трея во время выполнения). Источник — `scripts/icon.svg`.

## Источники распознавания текста

В Настройках можно добавить несколько источников — приложение пробует их по порядку, пока один не сработает:

- **Gemini** (`aistudio.google.com/apikey`) — бесплатный ключ, лучшее качество и понимание структуры (таблицы, кнопки, списки через JSON-разметку).
- **Groq** (`console.groq.com/keys`) — бесплатный ключ, второй провайдер для запасного варианта.
- **Локально (офлайн)** — `tesseract.js`, без ключа и без лимитов, работает на компьютере пользователя. Языковые данные (`rus+eng`) скачиваются один раз при первом использовании и кэшируются в `%APPDATA%/snap-notes/tesseract-cache`. Понимает только сырой текст, без структуры.
- **Экономный режим** (виден в настройках, если добавлен локальный источник) — сначала бесплатный локальный OCR достаёт текст, затем облачная модель только причёсывает уже готовый текст (это на порядок дешевле по токенам, чем отправка целой картинки), заметно экономя дневной лимит бесплатных ключей.

## Данные пользователя

- Заметки — отдельные `.json`-файлы в `%APPDATA%/snap-notes/notes` (мягкое удаление — заметка просто получает `deletedAt` и переезжает в корзину; корзина чистится автоматически по таймеру или вручную).
- Кэш скриншотов — `%APPDATA%/snap-notes/screenshot-cache`, ограничен по времени хранения, чистится автоматически и вручную.
- Настройки и API-ключи — зашифрованный `%APPDATA%/snap-notes/config.json` (`electron-store`).

Всё это управляется из вкладки «Настройки»: открыть папку с данными, экспортировать заметки, посмотреть, сколько места что занимает, очистить кэш, сбросить всё.

## Структура проекта

```
src/
├── shared/          # общие типы, IPC-каналы, пресеты OCR, темы, changelog
├── main/
│   ├── ai/           # провайдеры распознавания (gemini/groq/local) + роутер с фолбэком
│   ├── ...           # окна, трей, хоткеи, IPC, скриншоты, корзина, апдейтер
├── preload/          # безопасный мост contextBridge → window.api
└── renderer/
    └── src/
        ├── components/   # UI: карточки, редактор, настройки, инструкция, визард, корзина
        ├── store/         # Zustand-стор
        └── styles/
```
