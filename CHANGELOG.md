# Changelog

- Починена иконка в трее — в собранном установщике она раньше не находилась и трей оставался пустым
- Окно приложения теперь мгновенно меняет цвет фона при смене темы (и открывается сразу в правильном цвете, без белой вспышки в тёмной теме)
- Починены тумблеры в Настройках — в состоянии «включено» кружок вылезал за пределы своей дорожки

## 1.1.1 — 2026-08-11

- Починено автообновление — теперь приложение действительно само проверяет новые версии (при запуске и каждые 4 часа), скачивает их в фоне и показывает кнопку «Перезапустить». Начиная с этой версии обновляться вручную больше не понадобится

## 1.1.0 — 2026-08-11

- Редактор заметок теперь закреплённая панель справа, а не всплывающее окно поверх интерфейса
- Встроенный редактор форматирования: жирный, подчёркнутый, зачёркнутый, выделение цветом
- Пресеты распознавания текста — «Как есть», «Формально», «Свободно», «Структурно»: таблицы и колонки больше не сливаются в одну строку
- 8 тем оформления: зелёная, красная, синяя, жёлтая — каждая в светлом и тёмном варианте
- Обновлённый дизайн в духе Google Docs
- Ускорен захват скриншота области экрана
- Несколько ключей Gemini и Groq с автоматическим переключением при ошибке или лимите, плюс локальное офлайн-распознавание (Tesseract) без ключа и без лимитов
- Экономный режим: локальный OCR бесплатно достаёт текст, облачная модель только причёсывает — расходует в разы меньше лимита
- Корзина с автоудалением и восстановлением заметок
- Эмодзи-аватарки заметок с подсказками по смыслу текста
- Прозрачная статистика хранилища: размер заметок и кэша скриншотов, счётчик символов, ручная и автоматическая очистка кэша по таймеру
