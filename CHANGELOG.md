# Changelog

## 1.5.0 — 2026-10-02

- ИИ-источников стало 14: к Gemini, Groq, ChatGPT, OpenAI API и Anthropic API добавлены OpenRouter, Mistral, Cerebras, Cloudflare Workers AI, NVIDIA NIM, Cohere, Hugging Face и необязательный Modal OCR для продвинутых. Tesseract по-прежнему всегда работает офлайн
- Раздел «ИИ и распознавание» теперь единый: режим, «Что предпочитать» (бесплатные / лучшее качество / самые быстрые / свой порядок), карточки источников с кнопкой «Получить ключ» на официальную страницу, моделью, проверкой подключения и лимитами
- Скриншот уходит только источникам, которые умеют читать изображения. Текстовые модели (Cerebras, Cohere и др.) получают текст после Tesseract. Если лимит кончился или источник не ответил, Snap Notes идёт по цепочке дальше и в крайнем случае всё равно создаёт заметку
- Mistral OCR и OCR на Modal возвращают Markdown, который превращается в блоки заметки на вашем компьютере — без второго запроса к ИИ
- Остаток запросов и время сброса показываются, только если их сообщает провайдер (Groq, Cerebras, OpenRouter, Mistral и др.). Если нет — «Остаток не сообщается» и отдельно «Локальный счётчик Snap Notes». Бесплатная квота Cloudflare показана как документированный факт, без выдуманных процентов
- OpenRouter: «Автоматически (бесплатные)» выбирает бесплатную модель под задачу; для скриншота — только с поддержкой изображений. Рядом с моделями — FREE и PAID
- Для ключей: показать, скопировать (буфер очищается через минуту), заменить. «Дополнительно → Экспорт API-ключей» сохраняет .env только после предупреждения и выбора файла в стандартном окне Windows
- Тёмная тема стала заметно контрастнее: карточки отделены от фона, чёткие границы полей, заметный фокус с клавиатуры, читаемые placeholder'ы, ссылки, таблицы и код в редакторе. Светлая тема не изменилась

## 1.4.0 — 2026-09-30

- Новый интерфейс: слева панель разделов (Заметки, статус ИИ, Справка, Настройки), рядом боковая панель раздела — поиск, «Все», «Закреплённые», «Корзина» и недавние заметки. Спокойные нейтральные цвета, акцентный цвет только у главных кнопок, тёмная тема без чистого чёрного
- Действия с заметкой — в меню «…», по наведению и по правому клику; редактор открывается справа, а на узком окне занимает всё место. Удаление больше не спрашивает подтверждение — заметка уходит в корзину, а в уведомлении есть «Отменить»
- Палитра команд Ctrl+K: любая заметка и любое действие с клавиатуры. Ещё клавиши: Ctrl+N — новая заметка, Ctrl+F — поиск, Ctrl+\ — боковая панель, Ctrl+, — настройки
- Настройки разбиты на разделы (Общие, Хоткеи, Распознавание, Источники, Использование, Хранилище, Экспорт и сброс, О программе); тема — отдельно оформление и акцентный цвет
- Захват встаёт туда, где стоит курсор в заметке (абзац аккуратно разрезается), а не только в конец
- Маленькое окно поверх всех приложений: «Распознаю…», затем «Добавлено в „…“» с кнопками «Отменить» и «Открыть заметку» — исчезает само
- Сессия захвата (Ctrl+Alt+S): несколько фрагментов подряд в одну заметку со счётчиком; завершить — тем же хоткеем, Enter/Esc в режиме выделения или кнопкой «Готово»
- У каждого распознанного фрагмента — меню: «Показать оригинал», «Проверить распознавание» (скриншот рядом с текстом), «Источник», «Привести в порядок», действия ИИ, копирование и удаление
- Сомнительные места подчёркнуты; при наведении — «Низкая уверенность распознавания», оригинал для сверки и кнопка «Верно»
- Таблицы: добавление и удаление строк и столбцов, строка заголовка, копирование как Markdown, TSV и CSV. Блоки кода: Enter и Tab внутри кода, кнопки «Копировать код» и «Markdown»
- В меню заметки — копирование для AI, с форматированием для Word, как Markdown или текст, и экспорт в Word, PDF, Markdown и TXT
- Настройка «Если ни одна заметка не открыта»: сразу новая заметка или окно выбора. Все горячие клавиши можно изменить или отключить
- Исправлено: при быстром закрытии заметки после автосохранения текст мог задвоиться; заголовок, придуманный ИИ, мог стереться
- Заметки теперь хранятся в блочном формате (заголовки, списки, таблицы, код, цитаты, изображения). Старые заметки переводятся автоматически при первом запуске, перед этим создаётся резервная копия в папке backups
- Распознавание сохраняет структуру: уровни заголовков, списки, настоящие таблицы, блоки кода без изменений в отступах и символах, ссылки и email, кнопки интерфейса («Кнопка: Подключить»). Даже без интернета Tesseract восстанавливает заголовки, списки, таблицы и код
- Распознавание только исправляет ошибки OCR и никогда не переписывает текст. Стили «Формально/Свободно» убраны. Места, в которых ИИ или Tesseract не уверены, помечаются подчёркиванием
- К каждому захвату сохраняются оригинальный скриншот, время, приложение и окно, откуда он сделан, и способ распознавания
- «Документ из скриншота» стал «Захватом в новую заметку»: работает с любым источником распознавания и сам придумывает короткое название
- Длинный скриншот теперь превращается в структурированный документ, а не в одну картинку: очень длинная страница распознаётся частями, повторы на стыках убираются
- Новые горячие клавиши: «Скопировать заметку для AI» (Ctrl+Alt+C — чистый Markdown для ChatGPT/Claude) и «Открыть Snap Notes» (Ctrl+Alt+N)
- Экспорт заметки в TXT, Markdown, PDF и Word; копирование как текст, Markdown или форматированный текст для вставки в Word. Экспорт в Word сохраняет уровни заголовков, код и оформление таблиц
- Новый раздел «ИИ и распознавание»: подключите свой план ChatGPT (официальный вход «Sign in with ChatGPT», без API-ключа), Gemini, Groq, OpenAI API или Anthropic API. Tesseract всегда работает офлайн как последний запасной вариант
- Четыре режима: «Лучшее качество», «Сбалансированно», «Экономно» (ИИ получает только текст) и «Только офлайн» (ничего не уходит в интернет)
- Автоматический переход на следующий ИИ, если у текущего закончился лимит, истёк вход, нет связи или модель недоступна. После сброса лимита источник сам возвращается в работу
- Приоритет источников перетаскиванием, выбор модели из реального списка провайдера, «Беречь заканчивающиеся лимиты»
- Экран «Использование ИИ» и индикатор на главном экране: остатки, проценты и обратный отсчёт до сброса — только когда их сообщает сам провайдер. Отдельно — собственная статистика запросов Snap Notes
- API-ключи теперь хранятся зашифрованными средствами Windows (DPAPI) и никогда не передаются в интерфейс. Старые ключи переносятся автоматически, с проверкой перед удалением старой копии
- Подписку Claude Pro/Max Anthropic не разрешает использовать сторонним приложениям — для Claude подключается Anthropic API

## 1.3.1 — 2026-08-26
